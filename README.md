1. **Zero-Clutter Diegetic Optical Viewfinder**:
   - The holographic dome opens completely unoccluded (`16:9` Open Matte temporal corpus + `200x140` SAM + DPT-MiDaS depth-displaced 3D relief).

2. **Bijective 5-Ring Coaxial Memory Orb (`L1`–`L3`, `R1`–`R2`)**:
   - Every visual change in the dome is driven by—and reflects back into—the 5 physical knurled rings (`L1:GEOM`, `L2:FOCUS`, `L3:MORPH`, `R1:LUMA`, `R2:TINT`), the 4-node SAM target selector (`1`–`4`), and the translucent white diegetic **C-Arc (`arch`)**.
3. **Real Practical Utility — Bespoke Bug & Birthday Cake Studio (`[B]`)**:
   - **`PATISSERIE.OS [CAKE]`**: Design any custom birthday cake for anyone. Type any recipient name or script (`HAPPY BIRTHDAY MAYA`, `生日快樂`, `ANA // 6·10·21`) to pipe live 3D crimson buttercream calligraphy across the cake crown; configure `1..12` flickering candles (`3200K`), blow out the candles with rising smoke curls, morph between Cylinder, Rose-Crown, and 11-Flute Bundt topology, choose Vanilla/Ganache/Rose-Berry/Matcha/Gold glaze, and toggle 24 Smarties candies.
   - **`ENTOMOLOGY.OS [BUG]`**: Design any custom insect holotype. Specify binomial taxon and common name (`Carabus stellinae`, `Chrysina aurata`), tune `32..320_HEX` ommatidia facet density, sweep `430nm..635nm` thin-film chitin wavelength, grow `0..360` sensory setae bristles, and toggle asymmetric split optics.
   - **Archival Export & Shareable Blueprints**: Press the physical Red **`IMPRINT`** button on the Orb (or click **`IMPRINT MEMORY CARD (.PNG)`**) to export a `1280x880` Archival Memory Bearing Card `.png`, or click **`COPY LIVE LINK`** to share an exact parameterized URL (`?shot=redicing&insc=...`).
